# Prompt Master Criades V7.0.12

Casa Ribalta — generador local HTML de prompts visuals i microescenes bilingües.

## Novetats V7.0.12

- Nou **generador de microescena bilingüe ES + EN** vinculat a la mateixa localització, activitat, personatge i uniforme del prompt visual.
- Extensió seleccionable: aproximadament 150, 200, 250 o 300 paraules per idioma.
- Enfocament narratiu: automàtic, pensaments, diàleg amb la senyora, diàleg amb una altra minyona, anècdota, petit conflicte o rutina professional.
- Punt de vista en primera o tercera persona.
- **Bilingual Coherence Lock**: les dues llengües han de narrar exactament els mateixos fets, personatges, diàlegs i cronologia.
- Botons separats per copiar el prompt d'imatge, el prompt narratiu o el paquet complet; exportació TXT conjunta.
- Correcció de **Habitació del personal**: dormitori residencial privat, amb llit(s), armari domèstic de fusta, escriptori i finestra; prohibides taquilles metàl·liques i aspecte d'hotel/fàbrica/gimnàs.
- Correcció de **Bany del personal**: bany domèstic petit i complet, no vestidor institucional.
- Nou bloqueig de botons per als uniformes amb pitet: espaiat realista, màxim dos visibles i cap botó sobre la superfície del pitet.
- Uniforme formal C: exactament quatre botons totals.
- Nous tractaments de teixit de servei: **Satén mate**, **Ras (satén)** i **Faille satinada**, amb bloquejos específics de brillantor, textura i caiguda.

## Ús

Obre `prompt_master_criades_v7_0_12.html` en un navegador modern. No necessita servidor ni instal·lació.

Els presets continuen guardant-se localment al navegador mitjançant `localStorage` i es poden exportar/importar en JSON.
